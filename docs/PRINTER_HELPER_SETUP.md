# Zaylotix Printer Helper — ইনস্টল ও টেস্ট গাইড (Phase 43)

এটা **একদম আলাদা, ছোট** একটা Android অ্যাপ — শুধু Bluetooth প্রিন্টারে কথা
বলার জন্য। মূল Zaylotix POS অ্যাপ **একটুও বদলায়নি**, এটা একটা দ্বিতীয়,
ঐচ্ছিক অ্যাপ। পরিকল্পনা: `docs/BT_PRINT_PLAN.md` বিকল্প ক।

## ১. ফোনে অ্যাপটা বসানো (একবারই)

ডিবাগ APK ফাইল আপনার PC-তে এখানে আছে:
```
D:\mobile pos\printer-helper\app\build\outputs\apk\debug\app-debug.apk
```

1. এই ফাইলটা ফোনে পাঠান (USB কেবল / WhatsApp নিজেকে / Google Drive — যেকোনো
   একটা, আগে TWA APK যেভাবে বসিয়েছিলেন একই নিয়মে)।
2. ফোনে ফাইলটাতে ট্যাপ করুন, "Install from unknown sources" চাইলে অনুমতি
   দিন।
3. **"Zaylotix Printer"** নামে একটা নতুন অ্যাপ আইকন আসবে (সবুজ, প্রিন্টার
   আইকন)।

## ২. প্রিন্টার বাছাই (একবারই)

1. আগে ফোনের **Settings → Bluetooth**-এ গিয়ে প্রিন্টারটা (XP-365B) **pair**
   করে রাখুন (এটা আগে থেকেই করা থাকার কথা, RawBT পরীক্ষার সময় করেছিলেন)।
2. **"Zaylotix Printer"** অ্যাপ খুলুন → Bluetooth অনুমতি চাইলে **Allow**
   করুন।
3. নিচে paired ডিভাইসের তালিকায় প্রিন্টারের নাম দেখবেন — **ট্যাপ করে
   বাছুন**। উপরে "বর্তমান প্রিন্টার" লেখায় নামটা দেখাবে।
4. **"🧪 টেস্ট প্রিন্ট"** বাটনে চাপুন — একটা বর্ডার+ক্রস প্যাটার্নের টেস্ট
   লেবেল ছাপা হওয়ার কথা। **এটা সফল না হওয়া পর্যন্ত পরের ধাপে যাবেন না।**

## ৩. Zaylotix থেকে আসল লেবেল প্রিন্ট

1. Zaylotix অ্যাপ (আগের মতোই, একই TWA) খুলুন → বারকোড লেবেল পেজ।
2. প্রোডাক্ট/কপি-সংখ্যা বাছুন, "প্রিভিউ" চাপুন — আগের মতোই প্রিভিউ খুলবে।
3. এবার প্রিভিউর উপরে নতুন বাটন **"📱 Bluetooth-এ প্রিন্ট"** দেখবেন (শুধু
   থার্মাল মোড চালু থাকলে দেখা যাবে — মেমো ও লেবেল সেটিংসে আগেই চালু করা
   আছে)। চাপুন।
4. ফোনের **শেয়ার-মেনু** খুলবে — সেখান থেকে **"Zaylotix Printer"** বাছুন।
5. প্রিন্টার অ্যাপ নিজে থেকে খুলে প্রতিটা লেবেল পাঠাবে, "প্রিন্ট হচ্ছে
   (১/৫)" জাতীয় অগ্রগতি দেখাবে, শেষে "✅ প্রিন্ট সফল" দেখালে বন্ধ করুন।

## সমস্যা হলে

- **"📱 Bluetooth-এ প্রিন্ট" বাটনই দেখাচ্ছে না** — ব্রাউজার পুরনো ক্যাশে
  আটকে থাকতে পারে (আগের মতোই: অ্যাপ সম্পূর্ণ বন্ধ করে আবার খুলুন, বা
  Chrome দিয়ে সরাসরি `pos.zaylotix.com` চেষ্টা করুন)।
- **শেয়ার-মেনুতে "Zaylotix Printer" দেখাচ্ছে না** — অ্যাপটা ঠিকমতো
  ইনস্টল হয়েছে কিনা, ফোনের অ্যাপ-তালিকায় আছে কিনা দেখুন।
- **"কোনো প্রিন্টার বাছা নেই" বার্তা** — আগে Zaylotix Printer অ্যাপ খুলে
  ধাপ ২ করুন।
- **প্রিন্ট শুরু হয় কিন্তু "❌ প্রিন্ট ব্যর্থ" আসে** — প্রিন্টার অফ/দূরে
  আছে কিনা, ধাপ ২-এর টেস্ট প্রিন্ট এখনো কাজ করে কিনা আবার চেক করুন।
- **ফাইনাল (release) APK**: `printer-helper/app/build/outputs/apk/release/app-release.apk`
  — Zaylotix-এর মূল কীস্টোর (D:\zaylotix-keystore-backup) দিয়ে সাইন করা,
  Zaylotix লোগো আইকনসহ। **আগের debug সংস্করণটা ফোন থেকে uninstall করে**
  তারপর এটা install করতে হবে (সিগনেচার আলাদা বলে উপরে বসবে না), এবং
  install-এর পর একবার অ্যাপ খুলে প্রিন্টারটা আবার বাছতে হবে।
  নতুন release বানাতে: `cd printer-helper && ./gradlew assembleRelease`
