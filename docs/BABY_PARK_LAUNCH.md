ও লঞ্চের ধাপগুলো।

## ১. ডিপ্লয়ের আগে — ব্যাকআপ

```
ssh -p 65002 u441890539@82.29.157.97 "cd domains/zaylotix.com/pos_app && php artisan zaylotix:backup"
```
(বিদ্যমান `php artisan zaylotix:backup` কমান্ড — নতুন কিছু নয়, নিশ্চিত করার
জন্য ডিপ্লয়ের ঠিক আগে একবার চালান। এরপর `storage/app/backups`-এ নতুন
ব্যাকআপ ফাইল আছে কিনা দেখে নিশ্চিত হয়ে নিন।)

## ২. ডিপ্লয় কমান্ড (ক্রমানুসারে)

```
ssh -p 65002 u441890539@82.29.157.97 "cd domains/zaylotix.com/pos_app && git pull origin main && php artisan migrate --force && php artisan config:clear && php artisan optimize:clear"
```

এই রিলিজে একটা নতুন migration আছে (`shops.default_variant_sizes`/
`default_variant_colors`, nullable — কোনো বিদ্যমান শপের ডেটা বদলায় না)।

## ৩. Baby Park সেটআপ (migrate-এর পরে, একবার)

```
ssh -p 65002 u441890539@82.29.157.97 "cd domains/zaylotix.com/pos_app && php artisan shop:setup-baby-park --dry-run"
```
আউটপুট দেখে ঠিকঠাক লাগলে, আসল রান (পাসওয়ার্ড টার্মিনালে শুধু একবার
দেখাবে — **এখনই কোথাও সেভ করে রাখুন**, আর দেখানো হবে না):

```
ssh -p 65002 u441890539@82.29.157.97 "cd domains/zaylotix.com/pos_app && php artisan shop:setup-baby-park"
```

নিজের কোনো পাসওয়ার্ড দিতে চাইলে:
```
php artisan shop:setup-baby-park --password="আপনার-পাসওয়ার্ড"
```

**এই কমান্ডটা নিরাপদে বারবার চালানো যায়** — দ্বিতীয়বার চালালে নতুন
কিছু ডুপ্লিকেট হবে না, শুধু ফিচার/ক্যাটাগরি আবার সিঙ্ক হবে।

সেটআপ শেষে কমান্ডটা একটা সারাংশ দেখাবে: Main shop ID, Branch ID, এবং
(যদি নতুন তৈরি হয়) পাসওয়ার্ড। লগইন আইডি: **01864987754**।

## ৪. দ্বিতীয় শপের ফোন নম্বর ঠিক করা (যখন রেডি হবেন)

## ৫. মালিকের জন্য ১ পাতার দ্রুত-শুরু গাইড

1. **লগইন**: pos.zaylotix.com → ফোন `01864987754` + দেওয়া পাসওয়ার্ড।
2. **শপ সুইচ**: উপরে/সাইডবারে একটা ড্রপডাউন দেখবেন (🏬 Baby Park /
   🏬 Baby Park — শাখা ২) — এখান থেকে কোন শাখায় কাজ করছেন বদলাতে পারবেন।
   যেই শাখায় থাকবেন, বিক্রি/রিপোর্ট সেই শাখার নামে রেকর্ড হবে, কিন্তু
   স্টক দুই শাখাতেই একসাথে কমবে/বাড়বে (শেয়ার্ড)।
3. **সাইজ/রং দিয়ে পণ্য তোলা**: Stock পেজ → নতুন পণ্য (নাম, ক্যাটাগরি,
   দাম দিন) → পণ্যের ভেতরে "গ্রিড" বাটনে ক্লিক করুন — সাইজ ও রংয়ের
   তালিকা আগে থেকেই ভরা থাকবে (Accounts পেজে পরিবর্তন করা যায়), প্রতি
   ঘরে স্টক সংখ্যা লিখে একবারে সব সাইজ/রং যুক্ত করুন।
4. **বিক্রি (POS)**: Sell পেজ → প্রোডাক্ট খুঁজুন বা বারকোড স্ক্যান করুন
   → সাইজ/রং চিপ থেকে সঠিকটা বাছুন → কার্টে যুক্ত হবে → পেমেন্ট নিয়ে
   বিল সম্পন্ন করুন।
5. **অফলাইন বিক্রি**: ইন্টারনেট চলে গেলেও Sell পেজ কাজ করবে — বিল একটা
   "⏳ অফলাইন বিল" হিসেবে সেভ হবে, প্রিন্ট/WhatsApp বাটনও কাজ করবে।
   ইন্টারনেট ফিরলে এমনিতেই সিঙ্ক হয়ে যাবে। পেন্ডিং বিল দেখতে/বাতিল
   করতে 🔄 বাটন চাপুন।
6. **রিপোর্টে দুই শাখার তুলনা**: Reports পেজ → নিচে "শাখা অনুযায়ী
   পণ্যের লাভ" ও "শাখা অনুযায়ী সাইজ/কালার লাভ" সেকশন — কোন শাখা বেশি
   বিক্রি করছে, কোন সাইজ/রং কোথায় বেশি চলছে, সব দেখা যাবে। তারিখ
   ফিল্টার ও Excel এক্সপোর্ট দুটোই আছে।
7. **"সাইজ শেষ হয়ে আসছে"**: Reports পেজের "সাইজ/কালার স্টক" টেবিলে
   লাল রঙে ফ্ল্যাগ হবে — যেহেতু স্টক শেয়ার্ড, এটা উভয় শাখার জন্যই একই।
8. **দ্বিতীয় শাখার লগইন**: উপরের ধাপ ৪ অনুযায়ী, যখন রেডি হবেন।
